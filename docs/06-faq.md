# 6. คำถามที่เจอบ่อย

คำถามเหล่านี้มาจากการคุยจริงในแชททดสอบ

### ต้องเปิดคอมพิวเตอร์หรือ Claude Desktop ไว้ไหม
ไม่ต้อง แชท Claude Code บน cloud ทำงานบนเครื่องของ Anthropic ใช้จาก iPad หรือมือถืออย่างเดียวได้
จะต้องใช้ Mac ก็ต่อเมื่ออยากให้ Claude ทำงานกับไฟล์ที่อยู่ใน Mac เอง (ผ่าน Remote Control) ซึ่งงานนี้ไม่ได้ใช้

### เครื่อง cloud อยู่ที่ไหน
เป็นเซิร์ฟเวอร์ในศูนย์ข้อมูลของ Anthropic Claude ไม่รู้ว่าอยู่ประเทศไหน เป็นเครื่องชั่วคราวเฉพาะแชทนั้น คนอื่นเข้าไม่ได้
ถ้าทิ้งไว้นาน เครื่องจะถูกลบ งานที่ยังไม่ push ขึ้น GitHub จะหายไปด้วย

### งานจะขึ้น GitHub เองไหม
ไม่ขึ้นเอง ต้องสั่ง ("อัปขึ้น GitHub" หรือ "เอาเข้า") คลิปลูกค้าไม่ขึ้น GitHub เลย (ตั้งไว้ใน `.gitignore`)

### คนอื่นเข้ามาดู repo ได้ไหม
ถ้า repo เป็น Public ใครก็เปิดดูได้ แต่แก้ไม่ได้ ตั้งเป็น Private ได้ (ดู [02-setup.md](02-setup.md)) Claude ยังใช้ได้ตามปกติ

### ใช้ cloud ต้องซื้อเครดิตไหม
ไม่ต้องซื้อแยก แต่ต้องมีแพ็กเกจที่จ่ายเงินของ Claude (Pro / Max) การใช้งานนับรวมกับโควตาของแชทปกติ

### แนบคลิปในแชทไม่ได้ ไฟล์ใหญ่เกิน
อย่าแนบ ให้อัปขึ้น Google Drive แล้วส่งลิงก์โฟลเดอร์ Claude ดึงไฟล์เต็ม 4K ได้ (ต้องตั้ง network ตาม [02-setup.md](02-setup.md))

### บอกตำแหน่งโฟลเดอร์ใน iPad ให้ Claude เปิดได้ไหม
ไม่ได้ เครื่อง cloud มองไม่เห็นไฟล์ใน iPad หรือ iCloud สิ่งที่ Claude เห็นมีแค่ที่แนบในแชท หรือลิงก์จาก Drive

### ถ้าอัป skill ผ่าน claude.ai (แชทปกติ) จะสั่งตัดคลิปในแชทได้ไหม
ได้บางส่วน แชทปกติรับไฟล์ได้แค่ที่แนบ ดึงจาก Drive แบบไฟล์ใหญ่ไม่ได้ และ HyperFrames อาจ render ไม่ได้ งานตัดคลิปจริงใช้ Claude Code บน cloud (repo นี้) ดีกว่า

### Claude เลือกช่วงคลิปเองได้ไหม
ได้ Claude ดูภาพจากคลิปเป็นช่วงๆ (ไม่ได้ดูแบบวิดีโอต่อเนื่อง) และใช้ video-understand ให้คะแนน แต่ควรตรวจภาพตรวจของทุกช็อตด้วย (ดูบทเรียนข้อ 2 ใน [05-lessons.md](05-lessons.md))

### Claude ฟังเสียงได้ไหม
ฟังเองไม่ได้ ต้องถอดเสียงเป็นข้อความด้วย Whisper ก่อน หรือส่งสคริปต์มาให้

### Whisper ใช้ได้ไหม
ใช้อยู่แล้ว (faster-whisper) ขนาด small เร็วแต่ผิดหลายคำ large-v3 แม่นแต่ช้าเกินไปบนเครื่องที่ไม่มีการ์ดจอ

### คลิปที่ทำเสร็จอยู่ที่ไหน เซฟยังไง
ส่งในแชทเป็นการ์ดไฟล์ บน iPad หน้าตัวอย่างไม่มีปุ่มดาวน์โหลด ให้ Claude ทำหน้า Artifact ที่มีปุ่ม "บันทึกวิดีโอลงเครื่อง" ให้ (ไฟล์ 720p ไม่เกิน 15MB)

### ไฟล์เล็ก (720p) คุณภาพแย่ลงไหม
แย่ลงเล็กน้อย บนมือถือแทบไม่เห็นความต่าง สำหรับโพสต์จริงควรใช้ไฟล์ 1080p ตัวเต็ม เพราะ TikTok/Reels บีบไฟล์ซ้ำอยู่แล้ว
