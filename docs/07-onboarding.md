# 7. สัมภาษณ์เจ้าของธุรกิจ (ขั้นที่ 4 ของการตั้งค่า)

ก่อนทำคลิปแรก Claude ต้องเข้าใจธุรกิจและคอนเซปต์ของเจ้าของก่อน ไฟล์นี้คือชุดคำถามที่ Claude ใช้ถาม
คำตอบเก็บไว้ที่ [business-profile.md](../business-profile.md) และ [brand.json](../brand.json) ซึ่ง Claude อ่านทุกครั้งก่อนเริ่มงาน

## กติกาการถาม (สำหรับ Claude)

- ถามด้วยเครื่องมือถามแบบเลือกตอบ (AskUserQuestion) **ครั้งละไม่เกิน 4 ข้อ** ตามหมวดด้านล่าง
- **ทุกข้อต้องมีตัวเลือก `ข้ามไว้ก่อน` และ `ไม่สะดวกตอบ`** เสมอ ช่องพิมพ์เอง (Other) มีให้อัตโนมัติ
  - `ข้ามไว้ก่อน` = บันทึกเป็น `⏳ รอคำตอบ` แล้วถามใหม่ตอนเริ่มงานที่ต้องใช้ข้อมูลนี้
  - `ไม่สะดวกตอบ` = บันทึกเป็น `— ไม่ระบุ` แล้ว **ห้ามถามข้อนี้ซ้ำ** ใช้ค่าเริ่มต้นแทน
- ตัวเลือกที่มีให้เลือกในแต่ละข้อ มี 2 ตัวเลือกหลัก + 2 ตัวเลือกข้าม (ข้อจำกัดของเครื่องมือคือ 4 ตัวเลือก) ถ้าคำตอบไม่ตรงตัวเลือก ให้เจ้าของพิมพ์เองในช่อง Other
- ข้อที่เป็นข้อความเฉพาะ (ชื่อร้าน ชื่อคน) ให้ตัวเลือกหลักเป็นแนวทาง และบอกให้พิมพ์จริงในช่อง Other
- จบแต่ละหมวด สรุปสั้นๆ ว่าเข้าใจว่าอะไร ก่อนไปหมวดถัดไป
- จบทั้งหมด เขียน `business-profile.md` และแก้ `brand.json` แล้วเปิด PR ให้เจ้าของดู
- เจ้าของสั่ง "แก้โปรไฟล์" ได้ทุกเมื่อ ให้ถามเฉพาะหมวดที่ต้องการแก้
