# 5. บทเรียนจากการทดสอบ

สรุปจากการทดสอบจริง: คลิปรีวิวแนวตั้ง 30–60 วินาที จากฟุตเทจ 4K ~60 ไฟล์ + เสียงพากย์ภาษาไทย ทำซ้ำ 4 รอบจนได้ผลที่ดีมาก

## สิ่งที่เจ้าของงานติ และวิธีแก้ที่ใส่ไว้ในระบบแล้ว

| ปัญหา | สาเหตุ | แก้แล้วที่ |
|---|---|---|
| ไตเติ้ลมีแค่ตอนเปิด หลังจากนั้นเหลือแต่ซับ | ใส่ไตเติ้ลแค่ 3 วินาทีแรก | `titles` ในเทมเพลต ค้างบนจอทุกช่วง |
| ฟุตเทจติดช่วงตากล้องหันกล้องจะกดหยุด | ตัดรอบจุดที่ภาพคมสุด ซึ่งมักอยู่ท้ายคลิป, บางช็อตเริ่มที่วินาที 0 | `cut_shots.py` ข้าม 2 วิแรก/ท้าย และเลือกช่วงกล้องนิ่ง |
| ฟอนต์ไม่สวย | ระบบใช้ฟอนต์สำรอง | ฟอนต์จาก `brand.json` โหลดผ่าน npm |
| ซับไม่ตรงเสียง / ผิดคำ | ถอดเสียงไม่ได้ หรือโมเดลเล็กฟังผิด | ขอสคริปต์ก่อนเสมอ |
| ช้า | ทดลองเครื่องมือใหม่ระหว่างงาน (โมเดลถอดเสียงใหญ่, สร้างเพลงเอง) | โหมดเร็ว: ไม่ทดลองระหว่างงานจริง |
| เพลงที่สร้างเอง | MusicGen บน CPU ช้ามาก (>30 นาที) | กฎ: เพลงต้องมาจากเจ้าของงานเท่านั้น |

## เครื่องมือที่ลองแล้ว

| เครื่องมือ | ผล | ใช้ไหม |
|---|---|---|
| Whisper small (faster-whisper) | ~5 นาที/นาทีเสียง ผิดหลายคำ ให้เวลารายประโยค | ✅ เมื่อไม่มีสคริปต์ |
| Whisper large-v3 | แม่น แต่ >20 นาทีบน CPU | ❌ |
| Thonburian Whisper medium (`Vinxscribe/biodatlab-whisper-th-medium-faster`) | คำถูกกว่า small มาก แต่ ~14 นาที ไม่มีเวลารายประโยค ตกคำท้ายช่วง 30 วิ | ⚠️ เฉพาะเมื่อขอความแม่นยำสูง ใช้คู่กับเวลาจาก small |
| video-understand `cull.py` | คัด 60 คลิปใน ~10 นาที ให้คะแนนคม/นิ่ง/แสง | ✅ |
| hyperframes-registry | สูตรทรานสิชัน, light leak, เกรน, lower third, แสงวิ่งบนตัวหนังสือ | ✅ อยู่ใน `review-motion` |
| embedded-captions | รับแค่คลิปคนพูดหน้ากล้องช็อตเดียว | ❌ กับคลิปเสียงพากย์หลายช็อต (ยืมสไตล์ `anchor` มาแทน) |
| media-use SFX | whoosh, sparkle ในตัว (ใช้เชิงพาณิชย์ได้) | ✅ |
| media-use เพลง (MusicGen) | ช้า คุณภาพพอใช้ | ❌ ห้ามใช้ |

## ปัญหาทางเทคนิคและวิธีแก้

| ปัญหา | วิธีแก้ |
|---|---|
| แนบคลิปใหญ่ในแชทไม่ได้ | ดึงจาก Drive ตรงๆ (`drive_download.sh`) |
| ตัวเชื่อม Drive อัปโหลดไฟล์ใหญ่ไม่ได้ | ส่งงานกลับทางแชท |
| render error `gsap ... reading 'timeline'` | `cdn.jsdelivr.net` ถูกบล็อก ใช้ GSAP ในเครื่อง (`setup.sh` เตรียมให้) |
| huggingface 403 / xethub | เพิ่ม `*.hf.co` ใน network |
| openai-whisper ดาวน์โหลดโมเดลไม่ได้ | ใช้ faster-whisper |
| faster-whisper error `metadata_errors` | แปลงเสียงด้วย ffmpeg ก่อน (`transcribe.py` ทำให้แล้ว) |
| ดิสก์เต็ม | ลบคลิปดิบที่ไม่อยู่ในแผน, ไฟล์ render เก่า, โมเดลที่เลิกใช้ |
| iPad เซฟคลิปจากแชทไม่ได้ | หน้า Artifact + capability `downloads` |
| ffmpeg concat ต่อไฟล์ไม่ได้ | ใช้ path เต็มใน list (แก้ใน `cut_shots.py` แล้ว) |

## ข้อควรระวังเวลาแก้เทมเพลต HyperFrames

- ห้ามแอนิเมต `letterSpacing` (ภาพกระตุก) ใช้ `scale`
- `fromTo` ที่ใช้กับ element เดิมหลายครั้ง ต้องใส่ `immediateRender: false`
- กล่อง `overflow: hidden` ที่ซ่อนตัวหนังสือไทย ต้องเผื่อขอบบน ไม่งั้นวรรณยุกต์ขาด
- ห้ามใช้ CSS animation (seek ไม่ตรงเฟรม) ใช้ GSAP `tl.set` แทน
- จับเวลาที่ `<video>` หรือ wrapper อย่างใดอย่างหนึ่ง ห้ามทั้งคู่
- แสงวาบสีขาวเต็มจอ (flash) ให้สูงสุดไม่เกิน 0.8 ไม่งั้นแสบตา
- ทดสอบด้วย `npx hyperframes snapshot --at ...` ก่อน render ทุกครั้ง ประหยัดเวลามาก
