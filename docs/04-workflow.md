# 4. ขั้นตอนตัดคลิป: โหมดเร็ว + ถามก่อนทำ

หลักคือ **ขอของให้ครบตั้งแต่ต้น ไม่ทดลองระหว่างงาน และให้เจ้าของงานเห็นแผนก่อน render**
คลิป 1 นาทีจากฟุตเทจ ~60 ไฟล์ ใช้ราว 30–45 นาที

## ฝั่งเจ้าของงาน: สิ่งที่ต้องส่ง

1. **ลิงก์โฟลเดอร์ Google Drive** ที่มีฟุตเทจดิบทั้งหมด (4K ได้ ไม่ต้องย่อ) และไฟล์เสียงพากย์
2. **สคริปต์บทพากย์** (พิมพ์หรือวางในแชท) ทำให้ซับถูก 100% และประหยัดเวลาถอดเสียง 5–15 นาที
3. **ไฟล์เพลง** (mp3/m4a) ถ้าต้องการเพลงพื้นหลัง Claude จะไม่สร้างหรือหาเพลงให้
4. ความยาวคลิป และแนวคลิป หรือพิมพ์ว่า "ตัดสินใจเองได้เลย"

ตัวอย่างข้อความสั่งงาน:
> ตัดคลิปรีวิว 60 วิ ฟุตเทจกับเสียงพากย์อยู่ที่ <ลิงก์> สคริปต์ตามนี้ ... ใช้เพลงที่แนบมา

## ฝั่ง Claude: ขั้นตอน

งานแต่ละชิ้นเก็บใน `work/<ชื่องาน>/` (Git ข้ามโฟลเดอร์นี้):
```
work/<ชื่องาน>/
├── ids.txt          ← รายการไฟล์ Drive
├── raw/             ← ฟุตเทจดิบ
├── vo/              ← เสียงพากย์ + transcript
├── audio/           ← เพลงที่ได้รับ + mix.wav
├── cull/            ← ผลคัดฟุตเทจ
├── plan.json        ← แผนช็อต
├── shots-motion/    ← ช็อตที่ตัดแล้ว + check_all.jpg
├── content.json     ← หัวข้อ ซับ ป้ายชื่อ ทรานสิชัน
├── comp-motion/     ← โปรเจกต์ HyperFrames
└── out/             ← ไฟล์ส่งงาน
```

### ขั้น 0: เตรียมเครื่อง (~3 นาที)
```bash
bash scripts/setup.sh
```
อ่าน `brand.json` ถ้ายังเป็น `xxxx` ให้ถามข้อมูลแบรนด์ก่อน

### ขั้น 1: ดึงไฟล์ (~10 นาที / 12GB, รันเบื้องหลัง)
1. ใช้ตัวเชื่อม Google Drive: `search_files` ด้วย `parentId = '<folder id>'` ตาม `pageToken` จนครบทุกหน้า
2. เขียน `ids.txt` บรรทัดละ `<ชื่อไฟล์> <file id>`
```bash
scripts/drive_download.sh work/<งาน>/ids.txt work/<งาน>/raw
```

### ขั้น 2: เสียงพากย์ (เริ่มทันที ขนานกับขั้น 1–3)
- **มีสคริปต์:** หาเวลาของแต่ละประโยคจากจังหวะหยุด แล้วจับคู่กับสคริปต์
  ```bash
  ffmpeg -i vo.mp3 -af silencedetect=n=-35dB:d=0.25 -f null - 2>&1 | grep silence_
  ```
- **ไม่มีสคริปต์:** ถอดเสียงด้วย `small` (~5 นาที/นาทีเสียง) แล้วแก้คำผิดจากบริบท จดคำที่ไม่แน่ใจไว้ถามในขั้น 4
  ```bash
  python3 -I scripts/transcribe.py work/<งาน>/vo/vo.mp3 work/<งาน>/vo --model small
  ```
  ห้ามใช้ large-v3 (ช้าเกิน) ส่วน Thonburian ใช้เฉพาะเมื่อเจ้าของงานขอความแม่นยำสูงและรอได้ (~14 นาที, ไม่มีเวลารายประโยค)

### ขั้น 3: คัดฟุตเทจ (~10 นาที / 60 ไฟล์)
```bash
python3 -B .agents/skills/video-understand/scripts/cull.py \
  --out-dir work/<งาน>/cull --cells 16 work/<งาน>/raw/*.mov
```
เปิดดู `sheet_*.png` ทุกแผ่น จัดกลุ่มคลิปตามเนื้อหา ตัดคลิปที่ติดป้าย `shaky` / `soft` ทิ้ง
- ตัวเลขในภาพรวมคือ **อันดับ ไม่ใช่ชื่อไฟล์** ดูชื่อจาก `cull.md` เสมอ
- คลิปพื้นหลังมืดได้คะแนนต่ำ แต่ถ้าเป็นช็อตสำคัญ (เช่นผลงานหลังทำ) ยังต้องใช้

### ขั้น 4: ส่งแผนให้เจ้าของงานดู ⏸️ รอคำตอบ
ส่งในแชทเป็นตารางสั้นๆ:
- ลำดับช็อต: เวลา → ภาพอะไร → ตรงกับคำพูดไหน
- หัวข้อของแต่ละช่วง (หัวข้อต้องค้างบนจอตลอดคลิป)
- ซับทั้งหมด (ทำเครื่องหมายคำที่เดา)
- เพลงที่จะใช้ และช่วงไหนของเพลง

แก้ตามที่เจ้าของงานบอก แล้วไปต่อ **อย่า render ก่อนได้คำตอบ** การแก้หลัง render เสียเวลา 15 นาทีต่อรอบ

### ขั้น 5: ตัดช็อต (~8 นาที)
เขียน `plan.json` (ดู [templates/review-captions/plan.example.json](../templates/review-captions/plan.example.json)) แล้ว:
```bash
python3 -I scripts/cut_shots.py work/<งาน>/plan.json work/<งาน>/raw work/<งาน>/shots-motion --head-pad 0.4
```
ดู `shots-motion/check_all.jpg` (แต่ละแถว = ภาพต้น / กลาง / ท้ายของช็อต) ถ้าช็อตไหนกล้องขยับ ใส่ `"start"` เองแล้วตัดใหม่
หลังได้ช็อตครบ ลบคลิปดิบที่ไม่ได้ใช้ เพื่อคืนพื้นที่ดิสก์

### ขั้น 6: เสียง (~1 นาที)
ถ้ามีเพลง หาช่วงที่เพลงเข้าดีและช่วงดังสุดตรงกับท้ายคลิป แล้วตัดเพลงก่อน:
```bash
ffmpeg -ss <วินาทีเริ่ม> -t <ความยาว> -i music.mp3 -af afade=t=in:d=0.4 work/<งาน>/audio/music-cut.wav
scripts/mix_audio.sh vo.mp3 <music-cut.wav หรือ none> work/<งาน>/audio/mix.wav <ความยาว> "<เวลาเปลี่ยนหัวข้อ>" <เวลาการ์ดจบ>
```

### ขั้น 7: ประกอบและ render (~15 นาที)
เขียน `content.json` (ดู [templates/review-motion/content.example.json](../templates/review-motion/content.example.json)):
- `hook` ข้อความเปิด 3 วินาทีแรก
- `titles` หัวข้อค้างบนจอทุกช่วง
- `captions` ซับ (`*คำ*` = สีแบรนด์, `|` = ขึ้นบรรทัดใหม่)
- `lower_thirds` ป้ายชื่อตอนช่างปรากฏตัว (ชื่อและตำแหน่งดึงจาก `brand.json` ถ้าไม่ใส่)
- `transitions` กำหนดทรานสิชันเฉพาะจุด: `blur` `slide` `zoom` `leak` `flash` `cut`
- `end_card.start` เวลาเริ่มการ์ดจบ (ชื่อร้านและปุ่มดึงจาก `brand.json`)

```bash
python3 -I templates/review-motion/build.py work/<งาน>/content.json work/<งาน>/comp-motion
cd work/<งาน>/comp-motion && npx hyperframes lint
npx hyperframes snapshot --at <จุดทรานสิชัน,จุดเปลี่ยนหัวข้อ,การ์ดจบ> --no-end
npx hyperframes render -o ../out/final.mp4 --quiet
```
ดูภาพ snapshot ก่อน render จริง: ตัวหนังสือไม่บังหน้า วรรณยุกต์ไม่ขาด ทรานสิชันไม่ขาวหรือดำทั้งจอ

### ขั้น 8: ส่งงาน
```bash
scripts/deliver.sh work/<งาน>/out/final.mp4 work/<งาน>/out/final-small.mp4
```
- ส่งทั้งสองไฟล์ในแชท (ตัวเต็มสำหรับโพสต์ ตัวเล็กสำหรับดูบนมือถือ)
- ถ้าเจ้าของงานเซฟจากแชทไม่ได้ (iPad) ทำหน้า Artifact ส่วนตัวที่มีวิดีโอตัวเล็กและปุ่มบันทึก (capability `downloads`)
- เตือนเรื่องเครดิตเพลงถ้าเพลงมาจากเว็บเพลงฟรี
