# 1. ภาพรวม: อะไรอยู่ที่ไหน

## สามส่วนที่ต้องเข้าใจ

| ส่วน | คืออะไร | เปรียบเหมือน |
|---|---|---|
| **iPad / มือถือ** | หน้าจอที่ใช้พิมพ์สั่งงานและดูผล | รีโมต |
| **เครื่อง cloud** | คอมพิวเตอร์ของ Anthropic ที่ Claude ทำงานอยู่ สร้างใหม่ให้ทุกแชท | คอมที่ยืมใช้ชั่วคราว |
| **GitHub repo** | โฟลเดอร์ถาวรบนอินเทอร์เน็ต เก็บคู่มือ สคริปต์ และ skill | ตู้เก็บของถาวร |
| **Google Drive** | ที่เก็บฟุตเทจและเสียงพากย์ | โกดังวัตถุดิบ |

**ไม่ต้องเปิดคอมพิวเตอร์ไว้** ทั้งหมดทำงานบน cloud

## ไฟล์แต่ละแบบอยู่ที่ไหน

| ไฟล์ | อยู่ที่ | ถาวรไหม |
|---|---|---|
| คู่มือ, สคริปต์, เทมเพลต, skill, brand.json | GitHub repo ของคุณ | ✅ ถาวร |
| ฟุตเทจดิบ, เสียงพากย์, เพลง | Google Drive ของคุณ | ✅ ถาวร |
| ฟุตเทจที่ดึงมาตัด | เครื่อง cloud: `work/<งาน>/raw/` | ❌ หายเมื่อเครื่องถูกลบ (ดึงใหม่จาก Drive ได้) |
| โปรแกรมที่ติดตั้ง (Chrome, Whisper, โมเดล) | เครื่อง cloud | ❌ หาย ต้องรัน `scripts/setup.sh` ใหม่ |
| คลิปที่ตัดเสร็จ | ส่งให้ในแชท | ต้องเซฟลงเครื่องเอง |

## คำศัพท์

- **repo (repository)**: โฟลเดอร์โปรเจกต์บน GitHub
- **commit / push**: บันทึกการเปลี่ยนแปลง แล้วส่งขึ้น GitHub ถ้าไม่ push งานจะหายไปพร้อมเครื่อง cloud
- **branch / PR (pull request)**: แยกงานออกมาทำก่อน แล้วขอรวมเข้า `main` (ฉบับหลัก)
- **skill**: ชุดคำสั่งและสคริปต์ที่สอน Claude ให้ทำงานเฉพาะทาง เช่น ตัดต่อวิดีโอ ถอดเสียง
- **HyperFrames**: เครื่องมือของ HeyGen ที่เขียนวิดีโอเป็นหน้าเว็บ (HTML) แล้ว render ออกมาเป็น MP4
- **render**: แปลงงานที่ออกแบบไว้ให้เป็นไฟล์วิดีโอ
- **Public / Private**: repo แบบ Public ใครก็เปิดดูได้ (แต่แก้ไม่ได้) แบบ Private เห็นแค่เจ้าของและคนที่เชิญ
