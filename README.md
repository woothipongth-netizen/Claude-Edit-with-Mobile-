# Claude Video Studio: ตัดต่อคลิปแนวตั้งด้วย Claude บน cloud

ชุดเครื่องมือให้ Claude Code (บน cloud) ตัดต่อคลิป TikTok / Reels ให้ธุรกิจของคุณ
สั่งงานจาก iPad หรือมือถือได้ ไม่ต้องเปิดคอมพิวเตอร์ไว้

**ทำอะไรได้:** รับฟุตเทจดิบ (4K ก็ได้) และเสียงพากย์จาก Google Drive → คัดช็อตอัตโนมัติ → ถอดเสียงภาษาไทยเป็นซับ →
ประกอบคลิปพร้อมทรานสิชัน หัวข้อ ซับ ป้ายชื่อ เพลง และการ์ดปิดท้าย → ส่งไฟล์ MP4 กลับมาในแชท

**เวลา:** คลิป 1 นาทีจากฟุตเทจ ~60 ไฟล์ ใช้ราว 30–45 นาที (ส่วนใหญ่เป็นเวลาดาวน์โหลดและ render)

## โครงสร้างไฟล์

```
├── README.md                  ← ไฟล์นี้
├── CLAUDE.md                  ← คำสั่งที่ Claude อ่านทุกครั้งที่เริ่มแชท
├── brand.json                 ← ข้อมูลแบรนด์ของคุณ (แก้ไฟล์นี้ไฟล์เดียว)
├── docs/                      ← คู่มือ (ภาษาไทย)
├── scripts/
│   ├── setup.sh               ← ติดตั้งโปรแกรมในเครื่อง cloud (รันครั้งแรกของทุกแชท)
│   ├── drive_download.sh      ← ดึงไฟล์จาก Google Drive
│   ├── transcribe.py          ← ถอดเสียงภาษาไทย (Whisper)
│   ├── cut_shots.py           ← ตัดช็อตจากฟุตเทจตามแผน (ข้ามหัว-ท้ายคลิป เลือกช่วงกล้องนิ่ง)
│   ├── mix_audio.sh           ← มิกซ์เสียงพากย์ + เพลง + เสียงเอฟเฟกต์
│   └── deliver.sh             ← ทำไฟล์เล็กสำหรับดูบนมือถือ
├── templates/
│   ├── review-motion/         ← เทมเพลตหลัก: ทรานสิชัน + โมชั่นกราฟิก (ใช้ตัวนี้)
│   └── review-captions/       ← เทมเพลตเรียบ: หัวข้อ + ซับ + การ์ดจบ
├── .agents/skills/            ← ตัว skill (5 ตัวที่ใช้จริง)
├── .claude/skills/            ← ทางลัดให้ Claude Code มองเห็น skill
├── skills-lock.json           ← เวอร์ชันของ skill ชุด HyperFrames
└── work/                      ← พื้นที่ทำงานแต่ละงาน (ไม่ขึ้น GitHub)
```

## ข้อห้าม

- ห้ามเก็บคลิปหรือรูปลูกค้าใน repo (`.gitignore` ตั้งให้ข้าม `.mp4` `.mov` และ `work/` ไว้แล้ว)
- ห้ามใส่ API key หรือรหัสผ่านในไฟล์ใดๆ ของ repo
- เพลงพื้นหลังต้องเป็นไฟล์ที่เจ้าของงานส่งมาเท่านั้น
